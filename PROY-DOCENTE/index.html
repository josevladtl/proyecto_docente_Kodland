POP IT!

¡El mejor juguete antiestrés: plástico de burbujas infinito!

¿Qué es Pop it?

Pop it se traduce literalmente como "explótalo". Es un juego infantil en el que el proceso se puede comparar con el estallido de un plástico de burbujas de embalaje. Pero a diferencia del plástico, los pop-it se pueden presionar con sensaciones y sonidos característicos "infinitos": decenas de burbujas de silicona simplemente se exprimen hacia el otro lado.

Reglas del juego

Los jugadores se turnan para presionar las burbujas. Es obligatorio terminar la fila que se comenzó. Se pueden presionar un máximo de 3 burbujas al mismo tiempo (deben estar juntas, no se pueden presionar varias burbujas a la vez si no están seguidas). ¡La tarea es hacer que el oponente se quede con la última burbuja! ¡Quien presione la última burbuja pierde!
